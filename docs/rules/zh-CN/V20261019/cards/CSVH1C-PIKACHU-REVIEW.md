## 1. 审核标准（按用户 2026-10-20 的里程碑要求）

- 卡文以**本机卡图**为准逐项核对（放大卡头与页脚核对 HP、属性、费用、伤害、弱抗、撤退、赛制标记、卡号），
  并与同目录 `metadata.json` 交叉核对；二者不一致时以卡图为准。
- 每条定义、招式、特性、效果绑定和印刷绑定的 `sourceOfTruth` 都记录：官方商品页 URL、
  卡图在本机仓库中的路径、完整 SHA-256 与图源。`npm run cn:release -- --verify-images` 重新核对全部卡图指纹。

## 4. 已知边界

- **LIG 的含义**：卡面页脚只有 `LIG`，本记录按卡表与本机卡库把它作为该印刷的编号，
  未把它解释为类型码或赛制标记；规制标记记为 `null`（未见）。这不影响任何规则执行（基本能量在开放赛制按属性准入）。
- **嵌套交换的效果保护**：`cn.coin@1` 包裹 `cn.switch@1` 时，宣告可用性按交换本身的候选判断，
  未像独立 `cn.switch@1` 那样逐只核对“不受效果影响”的保护重叠。本卡池没有任何保护效果，
  引入此类卡时须补测试或改为原生证明。
- 定义 ID 以名称＋首个审核印刷区分（例如 `cn:pokemon:pikachu-ex:csvh1c-008`）；
  同文重印应绑定同一定义，不同卡文须另立定义。
