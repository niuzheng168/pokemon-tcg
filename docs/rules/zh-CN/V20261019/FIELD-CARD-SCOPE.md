## 2. 核心判定表

| 情形 | 结论 | 证据强度 |

| Item／Supporter 从手牌以效果弃掉受 E29 自保护的场地 | 可以使用卡牌不等于成功弃掉该场地；受保护的弃置不执行，不能先把它改放逐 | E29；使用许可与实际执行独立 |
| 场地自身由在场效果产生 self 保护 | self 指这张实际物理场地卡，不是任意 Pokémon 或共享场地槽位；离场后该在场保护不再生效 | E29 的雷霆山文例及“只要在场上”的明确范围 |

正常替换是 I.B-04 的场地使出／替换流程，不是从手牌使出 Item／Supporter 的
效果。无需把它硬包装为可被 E29 遮罩的 `discardStadium` 效果才能复用去向处理。
反之，某张物品的说明文要求弃场地，不能因最终也是场地离场就冒充正常替换绕盾。
Stadium 在场主动效果的来源也不是“从手牌使出的物品／支援者”；不能只看
`category=trainer` 或只看它曾经来自手牌就认定 E29 匹配。

## 3. 物理主体、owner 与在场来源

- **主体**：唯一在场 Stadium 的实际 `instanceId`；self 保护只保护这一实例，
  不能保护后来占据槽位的新场地，不能从同 definitionId／同名卡继承旧盾。
  原场地按 I.B-04 先移走、新场地再入场；E29 没有许可旧盾跨此更换继续存在。
- **物理持有者**：决定弃牌／放逐的所属区域。**共享使用者**：按 I.B-04 及真实卡文
  决定谁宣告、谁付款、执行效果时谁是使用者。两者可能不同；不能拿 `source.owner`
  的便利字段替代被移动卡的实际 owner。
- **在场有效性**：原 Prism 场地去了放逐区，该物理实例仍在全局卡牌表中，
  不代表它的持续 self 保护仍有效。判断必须依赖当前场地确实仍为该实例及其来源
  可用性；不能把在场盾复制到可编辑 ongoing ledger 留存。
- **不是清空一切历史**：离场应停止该在场保护，不应删除它此前合法使用的来源、
  移动原因或回执。若其他已获审效果有自身期限，应按它自己的规则处理，
  不因这张场地离场而无依据地统统清除。
- **Prism 身份**：父线的不可变 `prismStar` 标志及 `sameName=1` 是软件表示，
  不是官方要求这些 JSON 属性。须由实际卡面／名称标记及获审来源固定；
  不能靠可编辑的 runtime flag、名称字符串含◇、旧 tag 或本报告 synthetic 卡
  自行获得 Prism 身份。NAME 也禁止为方便而删标记，合并本来不同的卡名。
  限制是每个同名 Prism 一张，不是全卡组所有不同名 Prism 合计只能一张。
  已获审的 `nameKey` 若保留此卡名区别，配合 `sameName=1` 即可表达该限制，
  无需再按去掉 Prism 标记的“本体名字”跨普通／Prism 强行合并限额。

## 4. 费用与 then：为何可以作一般推导

对于**普通弃手牌费用**，以下前提已经足够，不必因缺少每卡 FAQ 把整个机制未决：

1. 卡文要求选足 N 张符合费用选择器的真实手牌，COST 不允许少付。
2. PRISM 的“将被放到弃牌区”没有限定只因效果、只在场上或排除使用费用，
   所以这一次合法的弃牌移动也属于其覆盖范围。
3. 该规则替换目的地，不是说该卡不能被选作弃牌对象，也不是防止它离开手牌。
4. 因而对选足的 N 张逐张执行替代后的移动：Prism 去 lost，其余去 discard；
   实际离开手牌并支付的仍是 N 张。不能要求把 Prism 先非法放进 discard，
   才允许计算费用完成。

这是**去向替代规则的一般蕴含**，不是直接引用了一条未找到的费用 FAQ；
在本次核读的固定 primary 中，未发现与此普通费用／普通 then 推导相反的条款。
不应仅因没有逐卡 example 就把这两类普通动作全部转成未决。
特别说明文若另要求某卡实际存在于弃牌区，或后续效果需要那里的一张卡，
必须按真实区域判断；不能用“费用已付”伪造卡还在弃牌区。
费用自身的移动依然不能充当后续效果变化：COST 的空牌库等禁用条件仍要检查。
付款后投影应已将 Prism 放 lost，否则可能凭虚假的弃牌区资源证明后续可用。

对普通效果弃置也是同一原则：**先区分防止执行与改去向**。
E29 阻止本次弃置时没有移动；Prism 规则不能越过保护自行触发放逐。
实际执行弃置且被 Prism 改去向时已经执行了前文的规则修正版，
THEN 以该执行事实判定，不以 discard 数组增加了几张代替。
例如 synthetic 前文只弃一张 Prism，实际从场地移到 lost，前文有执行；
若前文只有一张受保护场地、根本未移动，则前文无执行，不能解锁 then。
前文同时成功处理特殊能量、场地却被挡时，SELECT 的分种处理与 THEN 的
至少一部分执行规则也不能被误改成整段失败。

PRISM 是卡牌根身份的特别规则：有效的任意原因 `wouldDiscard` 都应改去 lost，
不是额外施加的一次 Item／Supporter／Ability 效果，也不产生新的效果来源。
应保留原移动原因／原效果来源，另记录去向替代；E29 场地自保护与正常替换的
物理规则仍分开。KO 时替代的是 I.D 步骤3的目的地，不是撤销昏厥；
步骤4及原卡规则规定的奖赏处理仍正常进行，不能因卡不在 discard 就漏发奖赏。

## 5. 放逐区与真正缺证的组合

**不提供任意取回 lost 的通用动作。** 本次固定 PDF 与缓存官方 HTML 中，
查到的放逐条款是 PRISM 的去向规定，没有找到一般玩家可从放逐区拿回卡的行动。
因此本子集应将 lost 与 discard 分开，不让“从弃牌区取回”等操作扫描 lost，
也不能允许客户端直接重分类到手牌／牌库。
这是一项来源范围与软件门禁结论，**不是声称上述原件逐字规定“任何未来卡文
永远都不能从放逐区取回”**；若将来确有获审专门简中说明文，须另审其范围和实现。

若另有明文禁止该次移动，按 A 的禁止优先处理，不能借改去向绕过禁止；
这不应仅因缺少 Prism 专门 FAQ 就一概未决。
仅下列超出一般替代的具体问题保留未决／未支持，不牵连普通费用与普通 then：

- 两个不同去向替代同时竞争且相关卡文未给出适用顺序时，不能只凭本次 PRISM
  段决定其优先序；需补对应依据，不能自行引入国际版的替代排序。
- 新的“弃牌时”触发或特殊条件若区分**执行弃牌动作**与**实际进入弃牌区**，
  其事件定义需单独获审；本报告不把 ordinary then 的结论自动扩成所有这类触发。
  但明确按区域取牌的查询可直接判卡不在那里，不必也泛化成未决。
- ordinary 与 E29 同 subject 重叠、又没有其他已知可用性证明时，使用许可仍需组合依据；
  不因 subject 从 Pokémon 扩到 Stadium 就发明新的许可优先序。
  实际效果是否被保护阻止，与是否允许开始使用仍是两回事。

## 6. Synthetic 验收建议与交还

- A 持有的受 E29 保护 Prism 场地：B 正常使出异名场地，旧卡到 A.lost、
  新卡在场，旧 self 盾停止；同名使出仍按 I.B-04 拒绝。
- 同场地分别面对 hand Item、hand Supporter、Stadium 在场效果、普通替换：
  前两者按获审 E29 保护遮罩，后两者不能仅因来源统称 trainer 而误挡。
- B 使用 A 原有场地的共享效果，B 付自己的费用；被弃场地与其他卡逐张归物理
  owner。费用 Prism／普通混合时总支付数不变、目标区域各自正确，选择器不符仍拒绝。
- 亚莎形合成效果：只有特殊能量、只有场地、两类都有、其中一类受保护；
  各自处理，不把普通数量不足规则误当费用可少付。
- Prism 移动启动 then、全被保护不启动、部分执行启动；后文查 discard 找不到
  实际已去 lost 的 Prism；不依赖两个区域数组长度差来代表所有执行事实。
- Prism Pokémon 昏厥时逐卡处理自身与附着卡的各自身份；不能因为主体是 Prism
  就把普通附着卡也全部放逐。单纯使用招式／特性不凭 Prism 标记移除在场卡。
- 同名 Prism 两张拒绝、不同名各一不因“一张规则”误拒、带／不带标记不错误合名；
  未经逐卡来源审核的定义和任意 lost 回收命令保持拒绝。
