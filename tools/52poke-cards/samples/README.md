# 随仓库提供的 10 张样例卡图

这些是按用户要求单独纳入 Git 的小体积样例，**不是全量图片缓存**。
共 2,247,500 字节（约 2.25 MB），8 张简体发行版、2 张繁体发行版；
图片按原始字节保存，没有压缩重编码、裁剪或改写文字。

从仓库根目录运行（Python 3.11+，无需额外依赖或联网）：

```sh
python3 tools/52poke-cards/bootstrap_library.py
```

脚本读取完整压缩 metadata，创建 43,794 个可明确识别的实体 TCG 印刷版目录，
并把这 10 张图放进对应目录。例如：

```text
tools/52poke-cards/library/
└── zh-Hans/151C/001_151/
    ├── metadata.json
    └── image.png
```

卡号原文 `001/151` 保留在 metadata，目录用 `001_151`；没有 `tcg/` 层。
所有展示 metadata 仍为简体，图片保持实际发行语言。
`--no-samples` 可只建 metadata；`--language zh-Hans` 只复制 8 张简体图，
`--language zh-Hant` 只复制 2 张繁体图。

## 清单、校验与重复运行

[`manifest.json`](manifest.json) 逐张记录印刷 ID、发行语言、set、完整卡号、
相对文件名、大小、尺寸、SHA-256、公开图片/页面出处及 Wiki 页面修订/文本哈希。
来源 URL 的临时查询参数和本机缓存路径已移除，不把来源链接当作当前可下载保证。
`source_wiki_images` 是归档中的引用，不宣称样例图片与 Wiki 附件字节相同。

建库先核对全部样例字节及归档身份，再复制；不联网、不读取 NAS/图片缓存/密钥，
不运行 OCR 或模型。自定义其他归档时须使用匹配的样例，或显式 `--no-samples`。
校验 PNG 签名/尺寸不等于语义核准；原有匹配证据保留在清单中，没有伪称人工复核。
重复运行复用相同 SHA-256 的图片，不削弱原有来源证据、人工修正或主图；
已有不同图片保留为主图，样例另存为 `images/<SHA-256>.png`。
缺失或损坏的已登记图片会报错，不静默覆盖修复。
