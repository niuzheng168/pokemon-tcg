# 数据来源、修改与许可边界

仓库根目录 MIT 许可只涵盖代码，不将以下数据重新许可为 MIT：

- `snapshots/`：从神奇宝贝百科 2026.10.18 XML 归档提取的卡牌 metadata、
  转为简体的展示投影，以及来源审计。
- `manifests/`：相同归档提取/整理的图片引用、卡牌页面与印刷标识，结合站方最新文件
  元数据读取得到的真实附件 URL、大小、尺寸和内容哈希。
- `sources/`：标明来源的机器读取规范、robots 缓存和最新文件元数据响应。
- `samples/manifest.json`：10 张公开来源样例的印刷身份、出处、页面修订和图片哈希清单。

出处：**神奇宝贝百科及其贡献者**（https://wiki.52poke.com/）。
归档及修订归属记录在各记录的来源/修订链接、快照清单和文件读取批次中。
