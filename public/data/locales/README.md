# 中文展示资料（非对战引擎）

`zh-CN.js` 由仓库内的 `tools/52poke-cards/export_academy.py` 生成，只供展示层使用。
`zh-CN-audit.json` 记录卡名、招式名、版本关联和缓存原卡图覆盖情况。

- 来源：神奇宝贝百科及其贡献者，百科站方发布的 2026-10-18 XML 归档。
- 归档哈希、来源页及修订信息保存在导出文件的 `archive`、`sources` 字段。
- 对百科资料做了抽取、简体字形转换和有限展示整理；不冒充官方核准译文。
- 数据采用源站声明的 **CC BY-NC-SA 3.0**，不是仓库代码的 MIT 许可。
- 图片版权独立，仍属于原权利人；学习卡面也不被标注为官方扫描。
- 缺少中文字段、人工校核、扫描图或规则实现，均不因为导出这个模块而自动补齐。
- 引擎仍使用原 ID、原名和效果；这个模块不增加可对战的卡牌或改变存档格式。
